# 🐾 Garritas Nails - Sistema de Agendamiento de Citas

¡Bienvenido al repositorio oficial de **Garritas Nails**! Este proyecto es una aplicación web responsive diseñada para que las clientas de nuestro salón puedan agendar, personalizar y gestionar sus citas de manicura y pedicura de forma rápida, sencilla e intuitiva. 


## 🌟 Características Principales

Reserva de Citas en Línea: Selecciona fecha, hora y el tipo de servicio deseado en tiempo real.
Diseño Responsive: Optimizado para una experiencia fluida desde smartphones, tablets y computadoras.
* **Confirmación Inmediata:** Integración para enviar recordatorios de citas vía WhatsApp o correo electrónico.
